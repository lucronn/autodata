# Workshop loading progress

The customer Workshop retains six ordered flow stages: years, makes, models,
engine/trim, article index and article. A native `<progress>` element omits
`value` while a request is pending. Poll attempts, payment confirmation and model
work do not have a measurable denominator and never produce percentages.

The ordinary activity text describes the current operation. It is not a live
region. A separate polite status region announces completion, and a separate
alert announces critical errors. Background article/source/media work preserves
focus. Selection changes, cancellation, history, logout and current-rights denial
abort the active navigation generation before another callback can publish.

Article preparation is an explicit CSRF-protected POST. Detail polling thereafter
is observational, sequential and bounded by one absolute two-minute deadline;
Retry-After affects spacing without extending that deadline. Available source
remains readable during retryable errors and while canonical work runs. Only an
actual job identifier enables continued processing polls. A terminal failure or
review requirement does not erase readable source or pretend canonical success.

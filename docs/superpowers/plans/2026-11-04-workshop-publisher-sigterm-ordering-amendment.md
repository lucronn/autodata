**Goal:** Correct the dormant Python publisher executor's SIGTERM child leak without passing a blocked SIGTERM mask to its child or changing live-publication authority.

**Architecture:** Temporarily own SIGTERM in the main thread with a handler that only records cancellation. Block SIGTERM while installing/restoring ownership and during bounded cleanup, and restore the caller's unblocked mask before `Popen`. Check cancellation immediately before spawning, immediately after the child handle is assigned, throughout I/O and in short final-wait intervals; never raise from the temporary handler across `Popen` assignment.

**Tech Stack:** Python standard library; POSIX signal masks; unittest; temporary local subprocesses only.

**Spec:** `docs/superpowers/plans/2026-11-04-workshop-publisher-python-review-corrections.md` Task3 and original dormant adapter plan. This amendment replaces only Task3's instruction to keep SIGTERM blocked through `Popen`; all other correction scope and denial boundaries remain mandatory.

## Required ordering and behavior

1. Validate argv/environment and require the main thread, `pthread_sigmask` support and no active executor owner **before Popen**. Snapshot and block SIGTERM atomically with `pthread_sigmask(SIG_BLOCK,{SIGTERM})`. If the snapshot already contains SIGTERM, restore that exact mask and fail with fixed `missing_dependency` before spawning. Keep `process=None`, `cancelled=False`, saved handler/mask and ownership state established before installing the temporary handler.
2. Within an outer `try/finally`, install a temporary handler whose entire behavior is setting `cancelled=True`; it must not raise, spawn, log, call cleanup or invoke the previous handler. Restore the saved **unblocked** mask before `Popen`, inside that protected scope. A SIGTERM that became pending during handler installation is now delivered to the temporary handler and records the flag.
3. Check the flag before `Popen`; if set, raise fixed `AdapterError('operation_cancelled')` with no child. Invoke normal `Popen(..., start_new_session=True, umask=0o077)` with no preexec hook and the caller's original unblocked mask. During the call or just after its return but before Python assigns the child handle, the temporary handler only sets the flag and returns, so assignment completes without interruption by this cancellation handler.
4. Immediately after assigning `process`, check the flag inside the same cleanup scope. If set, raise the fixed cancellation exception and clean the now-owned group. A signal after this check is observed at the next check before I/O/wait work. Check cancellation at each selector loop iteration and before returning. Keep selector waits at most100ms. Replace the final long `process.wait` with at most100ms waits that repeatedly check the **same** absolute deadline and cancellation flag; do not reset or extend the operation budget. Preserve output caps and all credential/environment restrictions.
5. In the outer `finally`, block SIGTERM **before** cleanup. A further SIGTERM during cleanup remains pending instead of interrupting it. If a child exists, send SIGTERM to only that owned isolated group; wait/reap the leader for at most2s, escalate to SIGKILL on the same group even if its leader exited (a descendant may remain), then complete a bounded final wait/reap and close every pipe. Preserve fixed `cleanup_failed` reporting for incomplete cleanup; do not silently turn it into success. There is no remote cancellation/cleanup claim.
6. After all owned cleanup, restore the prior handler and clear executor ownership while SIGTERM is still blocked, then restore the exact prior mask as the **last** ownership action. A further pending SIGTERM follows the caller's restored handler only after child cleanup. If the caller's policy terminates the owner at that point, no isolated child remains. Restore on normal result, timeout, overflow, process-creation failure, cancellation and cleanup failure. Unsupported concurrent/nested invocation must not replace another active handler.
